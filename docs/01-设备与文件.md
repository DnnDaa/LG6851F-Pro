# 1. 购买后核对设备与文件

准备设备、原配电源、支持数据传输的USB线、网线及Windows电脑；源码编译另需区分大小写的Linux环境。核对铭牌上的LG6851F Pro与PCB/生产批次，保存自己购入时的原厂版本。公开图片遮住IMEI、序列号、MAC和标签密码。

资料和上游项目的既有验证集中在2024/2025批次；不能仅凭外壳相同推定其他批次兼容。原厂SSH入口是否存在也取决于原厂固件版本。短信注入失效不等于要反复刷写或清NV。

| 文件 | 用途 |
|---|---|
| `lg6851f-a-public-20261015-sysupgrade.tar.gz` | 已运行本项目A槽OpenWrt时网页升级 |
| `lg6851f-a-public-20261015-mtk.zip` | Windows首次刷入A槽，内含三镜像、DA与XML |
| `lg6851f-windows-flash-tools.zip` | MTK Flash Tool及随资料提供的USB驱动 |
| `lg6851f-public-source-20261015.tar.zst` | 完整公开工程源码归档，保留Linux权限与符号链接 |
| `SHA256SUMS.txt`、`firmware-manifest.json` | 哈希、来源和版本记录 |

本版只交付A槽最新成品，B槽保留自己的原厂救援系统。不提供通用NV、别人整机备份或所谓全盘一键格式化包。

Windows校验例子：

```powershell
Get-FileHash .\lg6851f-a-public-20261015-mtk.zip -Algorithm SHA256
```

对照同次发布的清单，不混用其他日期的boot、rootfs或XML。
