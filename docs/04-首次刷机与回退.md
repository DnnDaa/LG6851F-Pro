# 4. 首次安装 OpenWrt A 槽

## 分区对应

| 项目 | A槽 | B槽 |
|---|---|---|
| boot | mmcblk0p25，32MiB | mmcblk0p38，32MiB |
| rootfs | mmcblk0p26，128MiB | mmcblk0p39，128MiB |
| connsys_gnss | mmcblk0p14，8MiB | mmcblk0p27，8MiB |

misc是p1；厂商数据fh_data是p44、160MiB；user_data是p46。此表只是本项目已知布局，必须与自己设备的PARTNAME/大小核对。A boot内嵌root=p26，不能改名当B使用。

## Windows操作

1. 解压 `lg6851f-windows-flash-tools.zip`，按原驱动包说明安装USB驱动。电脑与设备间使用可传数据的线。这里保留了原包，不运行来源不明的一键软件。
2. 解压最新 `lg6851f-a-public-20261015-mtk.zip` 到短英文路径，例如 `C:\MT6990\public_a\`。MTK工具也放短英文路径。
3. 启动ThinModemFlashTool，载入 `download_package/download_agent/flash.xml`。
4. 选择 **Download Only**；确认只选择 `connsys_gnss_a`、`boot_a`、`rootfs_a`，且对应同一包内的三个镜像。不要选择Format All/Firmware Upgrade，不勾NV、fh_data、fh_conf、GPT、B槽或user_data。
5. 按工具要求进入下载连接与上电时序，等待明确Download OK。期间不拔线、不让电脑休眠。
6. 重新上电并等待首次初始化。电脑接LAN，若A已启动进入 `192.168.1.1`；若仍回到原厂B系统，先核对A镜像写入和设备布局，再使用项目槽位工具选择A，不要靠连续断电切槽。

MTK包只安排三A分区写入，不自动替你切换misc启动优先级。需要时，在仍可SSH的原厂系统上传 `tools/slots/lg6851f-slotctl.sh`，先查看：

```sh
sh /tmp/lg6851f-slotctl.sh show
```

确认自己的misc已备份、A三镜像正确刷入后：

```sh
sh /tmp/lg6851f-slotctl.sh a --i-have-backed-up-misc
reboot
```

工具只识别本型号的eMMC misc和BCAB布局；不符合就退出。保存修改前记录，改两槽优先级与目标槽重试字节，其余字节保留，并回读核对；失败尝试恢复原记录。它不下载固件，不覆盖NV，也不自动重启。

## 首启与回退

先在LAN设置root密码，再检查蜂窝、两频段、CPU温度和风扇。公开版从自己fh_data读取校准；若无线未启动，查看 `logread | grep lg6851f-public`，不要套用他人的e2p。

A能进入SSH时回到保留的原厂B：

```sh
sh /tmp/lg6851f-slotctl.sh b --i-have-backed-up-misc
reboot
```

A完全无法登录时使用自己已验证的MTK恢复方式与自己的备份，优先仅恢复受影响槽的配对boot/rootfs。不把他人的GPT、misc、NV或整盘镜像当通用救砖包。
