# 5. 网页升级与使用

最新版本：[v1.0.2 更新与验证范围](releases/v1.0.2.md)；下载：[v1.0.2 Release](https://github.com/DnnDaa/LG6851F-Pro/releases/tag/v1.0.2)。


## 仅A槽

确认 `/proc/cmdline` 同时显示 `bootslot=a` 和 `root=/dev/mmcblk0p26`。LuCI“系统 → 备份/升级”上传 `lg6851f-a-public-20261015-sysupgrade.tar.gz`，按页面校验结果操作。不是原厂网页直接升级包，不能上传到原厂管理页面或B槽OpenWrt。

升级包包含boot、rootfs、connsys三A镜像。升级逻辑会更新A优先级/重试状态并读回确认，保护B槽镜像与设备个性分区。不要把它描述为“完全不触碰bootctrl”，也不要只手动刷rootfs导致新旧内核/驱动混用。

## 首次公开版设置

- 电脑先接LAN，访问 `192.168.1.1`，设置root密码。
- 公共默认无线为 `LG6851F-Pro-2G` / `LG6851F-Pro-5G`；首次初始化生成随机密码，到无线页面查看或修改。
- 默认Wi-Fi MAC按本机eMMC标识与校准内容派生，跨重启稳定、两频段独立，是本地单播地址，不等同于铭牌MAC；避免不同设备复制作者的固定地址。
- 国家默认CN，使用者按实际所在地设置；发射功率是驱动允许范围内的上限，不能把上限等同于每次发射的实际功率。
- 蜂窝小区锁定默认不锁定；按自己的服务小区配置，查看原生读回与驻留匹配，不继承作者所在地的小区。
- 风扇“安静”是最低安全风量，不是停转；温控保护可覆盖手动请求。
- CPU四核共享policy0，按真实硬件频率表和温控限制调整。无线只有2.4G/5G，额外逻辑接口不代表有第三射频频段。
- swap保留512MiB。Nikki与OpenClash的订阅由自己配置；不要把配置导出到公开issue。

## 升级保留配置

标准网页升级使用原有固件文件/overlay刷新逻辑，保留用户设置。公开版首启只替换公共无线占位配置，后续已设置的SSID/密码不被强制重置。自行直接用MTK刷rootfs时，旧p46 overlay可能仍保留文件，不能仅凭包中版本判断运行版本；优先完整升级并检查实际文件和启动日志。

## 常见问题

**无线不启动、报校准缺失：** 核对自己p44的PARTNAME、大小与 `wlan/e2p`，恢复自己备份。公开包故意没有别人的工厂校准；不能靠安装通用EEPROM掩盖设备数据缺失。

**第一次启动慢：** 初始化用户层、密钥、蜂窝和无线可能比后续启动久。避免连续断电触发原厂回退/覆盖机制；保留启动日志再判断。

**本机iperf速度低于无线协商速率：** 协商速率不是有效吞吐；单流、方向、手机实现和空口会影响结果。既有用户反馈不是所有客户端/新批次的性能保证。

**状态数字缺失：** 此版保留同值信号刷新修复；模组真实失联时会清空过期数字。问题报告附版本、启动时间、页面错误和脱敏日志即可。
