# V2.10 · LG6851F Pro（systemfix-94）

发布日期：2026-10-29。沿用已适配的 OpenWrt / Linux **6.18.44** 旧分支，完整继承 systemfix-94；本版同时提供 **A 槽和 B 槽**网页升级包、MTK 包及工程源码归档。

## 本版与近期累积更新

- **IPv6**：wan6 通过 `@modem5g` 跟随蜂窝实际数据接口；LAN 使用 RA/DHCPv6 server，向有线和 Wi-Fi 客户端分发实际委派的前缀。此前实机 Windows 无线客户端已取得公网 IPv6；是否获得公网前缀仍取决于运营商。
- **无线新增/删除**：普通 AP 按目标 BSS 增删，稳定分配并复用空槽；修复休眠 BSS 再利用时配置路径丢失，避免因该问题连锁重配整个频段。前序现场完成同频新增/删除及连续复用测试；并非无限容量，仍受每频段原生 BSS 上限约束。
- **无线客户端**：修复 AP/客户端字段校验、wwan 伪设备绑定、APCLI 创建、扫描接口映射、直连网段路由，以及低 ACK 通知误触发断开和进程必需标志；保留同频 AP、Wi-Fi 7、160 MHz、MLO 及原厂认证流程。
- **TurboACC**：保留独立加速管理页，不包含 MTK 无线调参页。显示原生 HNAT/PPE/WED 与 fw4 状态，拥塞算法和队列管理独立配置；不以关闭硬件加速替代修复。
- **NAT**：提供默认、IPv4 **UDP** 全锥形、随机端口对称映射模式，默认使用原有 NAT。切换影响新连接；既有连接不强制清空。前序真实 STUN 测试核对了映射行为与全锥形 expectation；未经证明的第三方入站硬件卸载不作承诺。不能改变运营商上级 CGNAT。
- **CPU、内存和写盘**：合并短时间内重复 HNAT 硬件统计，减少公共 RPC/页面重复读取；CAKE 按需分配 tin，保留队列算法与容量；采样按需运行，页面隐藏或离开后停止相关轮询并清理回调。保留错误日志、温控、蜂窝恢复和必要持久化，不通过改显示公式、清缓存或删除保护功能制造低占用。
- **状态看板与 LuCI**：复用浏览器/设备已有缓存，实时样本到达后接替；保留“更新中”波浪点，不显示缓存秒数；冷入口复用设备快照。修复概览局部错误拖垮整页、已连接站点一直收集、主机名 MAC 大小写匹配、速率 `undefined MHz`、风扇档位高亮和中文静态字典路径。
- **排版和交互**：居中导航，统一主要响应式断点，避免中窄屏来回跳布局、菜单竖排及弹窗按钮越界；品牌字号保持稳定。
- **打包校验**：依据 APK 3 的包内 `f:S` 标记刷新文件校验记录，正确区分 SHA-1 与截断 SHA-256，避免重新打包后记录与真实文件不符。
- **蜂窝与设备功能**：保留原生拨号、频段/小区锁定、载波聚合显示、短信、流量、CPU 档位、风扇/五灯、OpenClash/Mihomo、Nikki 和现有硬件加速。移除原厂家长控制/流量监控的旧 QoS 流程，不恢复 MARK47/58 强制硬件 QID 映射。

## 下载和槽位

| 文件 | 用途 |
|---|---|
| `lg6851f-pro-V2.10-public-A-sysupgrade.tar.gz` | 已运行 A 槽 OpenWrt，且升级器支持 A 槽格式时使用 |
| `lg6851f-pro-V2.10-public-A-mtk.zip` | MTK Download Only，仅选 `connsys_gnss_a / boot_a / rootfs_a` |
| `lg6851f-pro-V2.10-public-B-sysupgrade.tar.gz` | 已运行 B 槽 OpenWrt，且升级器支持 B 槽格式时使用 |
| `lg6851f-pro-V2.10-public-B-mtk.zip` | MTK Download Only，仅选 `connsys_gnss_b / boot_b / rootfs_b` |
| `lg6851f-pro-V2.10-source.tar.gz` | 工程源码、改动源码及精确公开运行层/重打包输入 |
| `SHA256SUMS.txt`、两槽 manifest、`verification.json` | 文件校验和本轮验证记录 |

**A/B 是二选一的目标包，不是同时刷两槽。** 同槽网页升级不负责从原厂系统首次安装或跨槽迁移；旧固件若拒绝包格式，不要绕过检查。MTK 不格式化、不选 Firmware Upgrade，不勾选其他分区。A 包会覆盖 A 槽原系统；如果 A 槽保留原厂 SSH 救援系统，使用 B 包。B 包不写 A 槽固件，两包均不清理共享原厂 SSH 持久化目录。本次只离线制作与发布，没有操作任何设备槽位。

## 公开版与验证边界

公开版清除个人 Wi-Fi 密码、root 密码哈希、主机密钥、固定 MAC、订阅、短信/流量历史、小区锁定目标及供体校准数据。首次用网线进入 `192.168.1.1` 设置 root 密码；Wi-Fi 首启生成随机密码。无线从刷入设备自己的 `fh_data` **只读**取得校准数据，不携带另一台设备的完整校准备份。保留配置升级会保留使用者自己的配置。

本轮重新核对 A/B 启动签名、相同内核载荷、120 个模块与 94B 一致、完整 SquashFS 文件/权限回读、APK 文件哈希、网页/MTK 三镜像一致、ZIP CRC、槽位分区选择及启动确认字节边界。前序实机测试结果与本轮离线检查分开记录。公开 A/B 组合尚未重新刷入冷启动、跨设备、长期稳定性或性能验收；没有从零全量重新编译全部闭源组件，也不保证所有场景固定 1% CPU、游戏负载下无延迟或无限次/无限数量 BSS。

完整累积历史见仓库 `CHANGELOG.md`。历史 v1.0.2 的功能说明按当时实现保留；V2.10 的行为以上述说明为准。
