# v1.0.2 · LG6851F Pro

发布日期：2026-10-17。整合此前暂停发布期间的修复与最新 MCS 功率限幅、LuCI 后台恢复修正，无需依次刷入中间包。保留原厂 Wi-Fi、蜂窝及有线 HNAT/WED 路径、Nikki 及依赖、CPU 调频和 512 MiB swap。

## 状态看板与资源

- 信号进入页面请求一次，停留期间每 25 秒刷新；复用已有模组服务的真实测量与注册时间，离开页面停止额外请求，明确掉线时清除旧信号。
- CPU 占用与频率每 3 秒更新，内存和存储共用 15 秒缓存；首屏通过真实 CPU 计数基线统一展示资源数据，避免分批长时间空白。
- “簇 0”改为“CPU频率”；逐 PPE 展示已绑定项、实际容量与占比，下方增加 Linux 会话连接数。
- 温度显示 CPU、蜂窝模组、WIFI温度。CPU/md 多测点取有效最高值；WIFI温度来自 connsys 连接子系统，不等同于外置 Wi-Fi 射频芯片结温。
- 优化无线客户端与 DHCP 租约行高和布局、双频信道分行、隐藏 SSID 的 YES/NO、卡号按钮位置及明暗/其他主题可读性。

## 蜂窝、短信、流量与设备控制

- 修复首屏服务小区为空；区分服务小区与邻区测量，锁定后仍可出现邻区测量，不以邻区记录冒充已驻留匹配。
- 状态与小区统一展示原生锁定记录及驻留状态，保留开机恢复；“填入当前服务小区”与提交锁定分开操作。
- 短信使用设备本地会话列表，进入后自动刷新，支持从 SIM 同步与清除本地池。
- 修复流量服务 CRLF 导致无法启动；按日/计费周期统计、用量校正、上限和提醒。低优先级采样，约 30 分钟有变化才落盘；未采集的历史不凭空补造。
- 拨号与网络页面、AT 调试页面采用统一布局，保留真实状态、原厂接口和串行控制锁；移除重复模式配置入口。
- CPU、风扇、五灯控制适配明暗及其他主题；风扇温度单位保持同行，保留自定义 PWM、自动温控和过热保护。

## 无线扫描与功率

- libiwinfo 支持 vendor618 的 radio 名称解析及真实 phy 查找。无线扫描和信道分析可以共用原厂 AP 扫描路径；扫描等待有超时，不创建临时无线接口或强制重载。
- 双频设置独立保存，保留 BE/160 MHz 设置能力。无线速率继续由原厂固件自动选择，不固定 MCS/NSS/GI。
- 参照 mt76 的逐速率取较小值方式，通过原厂接口实现 `min(用户上限, 本机原厂该速率目标)`；降低功率时不再把已经低于上限的高速 MCS 一起降低。
- 移除无依据的 29/30 dBm 选择，只列当前本机原厂表支持范围内的整数上限；驱动默认保留半 dBm 值，可展开当前带宽的 HE/EHT 各 MCS 固件目标。
- 直接删除旧强制 AU/30 首启脚本，迁移旧无效功率值；保留现有国家、信道和频宽。固件目标不是仪器实测射频输出，也不保证特定吞吐。
- 修复功率读回的日志游标、末尾空格、异步回调、旧错误缓存及逐速率校验/失败回滚。

## LuCI 后台恢复

- 修复原生 ucode 请求处理中的 ubus 连接共享等待，LuCI 改由现有独立 CGI 入口运行；只迁移 LuCI 路由，保留其他自定义映射、HTTP/HTTPS 监听与证书设置，脚本超时最多 60 秒。
- 修复 Wi-Fi 编辑 `Cannot read properties of undefined (reading 'then')`：兼容 LuCI 基类同步返回空值，使用 `Promise.resolve()`。
- 无线页面使用新的版本化资源，避免旧浏览器缓存继续执行出错代码。

## 占用与稳定性

- 减少重复 AT/资源读取，公平 QoS 关闭时不保留无效循环；复用温度路径与已有模组状态缓存。
- 日志缓冲 64 KiB、软件 conntrack 上限 32768；限制网页并发请求和连接数，保留按需内存诊断命令。
- 不增加常驻信号采集进程，不定期 drop_caches，保留厂商模组恢复、内核/驱动、风扇与热保护机制。不承诺待机固定 0%/1%，也未证明长期无内存泄漏。

## 下载与使用

- `lg6851f-pro-v1.0.2-public-sysupgrade.tar.gz`：A 槽 LuCI 网页升级。
- `lg6851f-pro-v1.0.2-public-mtk.zip`：Download Only，仅选择 `connsys_gnss_a`、`boot_a`、`rootfs_a`；不格式化，不选 Firmware Upgrade，不写 NV/校准或 B 槽。
- `lg6851f-pro-v1.0.2-source.tar.zst`：与 v1.0.2 标签对应的完整工程源码，保留权限与符号链接。
- `SHA256SUMS.txt`、`firmware-manifest.json`：校验及构建/验证记录。

公开版清理个人 Wi-Fi 密码、固定 MAC、主机密钥、订阅与锁小区目标；首次安装从 LAN 设置 root 密码。Wi-Fi 首启生成随机密码，驱动从刷机设备自己的 fh_data 分区只读取得校准数据。保留配置升级保留使用者自己的设置，旧超范围功率会迁移为驱动默认。

## 验证边界

网页/MTK 三镜像一致性、完整 rootfs 文件和权限、隐私清理、原厂驱动哈希已核对。功率模型/netifd/迁移保留 430 项离线检查记录，最新重新执行 33 项同步 LuCI load 浏览器检查及 8 项 CGI 迁移检查；扫描等前序检查在源码中保留记录，不将其统称为本轮重跑。
